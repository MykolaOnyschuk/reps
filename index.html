Setup Supabase Sync

Quick Setup Steps:

1. Go to supabase.com and create a free account
2. Create a new project
3. Go to SQL Editor and run this:

CREATE TABLE logs ( id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY, user_id TEXT NOT NULL, date DATE NOT NULL, exercise TEXT NOT NULL, reps INT NOT NULL, created_at TIMESTAMP DEFAULT NOW(), UNIQUE(user_id, date, exercise) ); ALTER TABLE logs ENABLE ROW LEVEL SECURITY; CREATE POLICY "allow_public_insert" ON logs FOR INSERT WITH CHECK (true); CREATE POLICY "allow_public_select" ON logs FOR SELECT USING (true); CREATE POLICY "allow_public_update" ON logs FOR UPDATE USING (true); 4. Go to Settings → API and copy your Project URL and Anon Key
